# Legion RX 4.0.11 Alpha — Audio Engine

Основа: 4.0.10 Alpha Warmup Voice.

## Главное изменение
Аудио Legion RX переведено с набора независимых `HTMLAudioElement` на единый Web Audio Engine.

### Что изменено
- Один `AudioContext` для штатного звука приложения.
- Раздельные аудиошины `VOICE` и `SFX`.
  - VOICE: диктор, минутные отметки, стартовый отсчёт.
  - SFX: Bleep и HORN.
- Bleep/HORN больше не используют тот же канал, что голос диктора, и могут звучать поверх речи.
- Первый пользовательский жест (`pointer/touch/click/keyboard`) разблокирует AudioContext и запускает silent-buffer для мобильной политики воспроизведения.
- При возврате приложения из фона выполняется попытка `resume()` AudioContext (`visibilitychange`, `pageshow`, `focus`).
- Тест HORN/Bleep/«Хорошей гонки» сам проходит через общий Audio Engine.
- Диагностический сигнал неизвестного транспондера также перенесён на SFX-шину, чтобы не создавать второй AudioContext.
- Добавлен статус `AUDIO ENGINE: ГОТОВ / ОЖИДАЕТ КАСАНИЯ` в виджете диктора и настройках.
- PWA cache bump: `legion-rx-4-0-11-alpha-audio-engine-1`.

## Что НЕ менялось
- Прогрев 1–5 минут.
- Free Practice LapWiz через прогрев → HORN → заезд без перезапуска на старте.
- Нулевой первый проход после HORN (`СТАРТ ✓`).
- Подсчёт кругов и спортивная логика RallyCross.
- Пользовательские WAV/MP3 из 4.0.10.

## Временное исключение
Фраза приглашения участников на трассу пока остаётся через системный `SpeechSynthesis`, потому что отдельного WAV этой фразы ещё нет. Все записанные фразы, цифры, Bleep и HORN идут через новый Web Audio Engine.

## Полевой тест
На Android и iPhone проверить:
1. открыть приложение после полного закрытия;
2. первым действием нажать `Тест HORN` — звук должен появиться без изменения системной громкости;
3. свернуть приложение и вернуться, снова запустить тест;
4. проверить Bleep во время WAV-фразы диктора — речь не должна обрываться;
5. отдельно проверить Bluetooth-колонку при подключённом LapWiz на Android.
