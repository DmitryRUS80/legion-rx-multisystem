# CHANGELOG — 4.1.0 UI NEXT TEST 06

## Track Day: судейская коррекция кругов

Добавлен единый функциональный контур `removeTrackDayLap()` в основном приложении. Это не отдельный patch-файл и не визуальный слой.

При удалении ошибочного круга:
- круг исключается из `lapTimes`;
- `laps`, `bestLapMs`, `lastLapMs` пересчитываются из фактического списка оставшихся кругов;
- среднее время автоматически пересчитывается через существующий `lapSummary()`;
- рейтинг свободной практики перестраивается через существующий `rankTrackPilots()`;
- коррекция сохраняется в `TrackDay.corrections[]` с пилотом, номером, временем и датой.

Функция доступна:
- в активной Free Practice;
- в завершённой текущей сессии;
- в сохранённой истории Track Day.

## Автоинформатор Free Practice

`processTrackPass()` теперь проверяет абсолютный лучший круг всей Track Day до добавления нового результата. Если новый круг быстрее текущего лучшего, вызывается существующая `announceBestLap(pilot)`. Используются существующий системный файл `new_best_lap.wav` и существующая локальная запись имени пилота.

## Совместимость

Не изменялись:
- `SPORT_RULES` RallyCross;
- квалификационные очки и BEST 3;
- A1/A2/A3 и Best 2 of 3;
- чемпионатные очки;
- BLE/LapWiz transport;
- START/STOP пакеты;
- `writeValueWithoutResponse`;
- ключи `legionrx4_track_days` и `legionrx4_active_track_day`.

Старые Track Day получают `schemaVersion: 2` и `corrections: []` при загрузке без удаления прежних данных.
