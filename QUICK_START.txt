LEGION RX 4.0.8 ALPHA — QUICK START

1. Загрузите содержимое архива в корень GitHub Pages репозитория.
2. В Настройки → Диктор · старт:
   - включите «Озвучка старта»;
   - выберите Полный или Короткий сценарий;
   - задайте отсчёт 1–10 секунд.
3. Кнопки «Тест Хорошей гонки», «Тест HORN» и «Тест Bleep» позволяют проверить звук.
4. В гонке нажмите СТАРТ — диктор отработает последовательность, затем HORN и START.
5. Bleep звучит на принятом проходе LapWiz зарегистрированного транспондера.

Для Web Bluetooth: Android/Windows Chrome + HTTPS.
