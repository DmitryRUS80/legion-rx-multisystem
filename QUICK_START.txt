LEGION RX 4.0.6 ALPHA — QUICK START

1. Откройте index.html для проверки интерфейса.
2. Главная → Ралли-кросс → создайте событие.
3. Добавьте минимум двух пилотов.
4. Выберите отдельно правило квалификации и финалов: время или круги.
5. Сформируйте заезды и откройте пульт.
6. Для LapWiz загрузите сборку на HTTPS (GitHub Pages) и откройте в Android Chrome / Windows Chrome с BLE.
7. После финального протокола нажмите «Завершить» — соревнование уйдёт в Архив.
8. Архив → «Восстановить в работу» возвращает сохранённую гонку.
9. Чемпионаты → «Войти в чемпионат» → Этапы / Расписание / Пилоты / Рейтинг / Настройки.
