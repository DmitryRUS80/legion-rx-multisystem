LEGION RX 4.0.4 ALPHA — БЫСТРЫЙ ЗАПУСК

1. Распакуйте ZIP полностью.
2. Откройте index.html двойным кликом.
3. На главной странице в верхней панели есть кнопка «Дизайн».
4. Нажмите «Дизайн» — справа откроется Design Lab.
5. Двигайте ползунки «Карточки», «Кнопки», «Главный баннер» и т.д. Изменения видны сразу.
6. «Сохранить» фиксирует значения в браузере.

Если JavaScript не запустится, вместо пустого экрана появится красный блок с конкретной ошибкой.

LapWiz по Bluetooth проверяется только на Android Chrome + HTTPS; локальный index.html нужен для UI и спортивной логики.
