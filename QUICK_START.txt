LEGION RX 4.1.0 UI NEXT TEST 02

GITHUB PAGES:
1. Распаковать архив.
2. Содержимое папки Legion_RX_4.1.0_UI_NEXT_TEST_02 положить в корень репозитория.
3. index.html, sw.js, ui-next.css, ui-next.js, flags, audio, icons должны лежать на одном уровне.
4. После обновления GitHub Pages открыть приложение и обновить страницу. TEST 02 использует новый offline cache, поэтому старый TEST 01 не должен подменять CSS/JS.

ПРОВЕРИТЬ ПЕРВЫМ:
- Desktop 1792x864 / 1920x1080: крупные строки, примерно 8–10/10–11 видимых пилотов.
- Android tablet landscape: полная ширина таблицы без наложений.
- Android/iPad portrait >=600 CSS px: все метрики + переключатели под пультом.
- Реальный LapWiz: подключение, START/STOP, первый проход START без круга, второй проход = первый круг.
