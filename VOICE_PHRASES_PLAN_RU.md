# Legion RX — план вспомогательных фраз диктора

Все файлы лучше записывать одним голосом: WAV mono, 48 kHz, 16 bit. Фразы должны быть короткими, без музыки и длинной тишины в начале или конце.

## Вызов на старт

| Файл | Текст |
| --- | --- |
| `one_minute_left.wav` | «До окончания заезда одна минута.» |
| `heat_next_prepare.wav` | «Участники следующего заезда, приготовиться.» |
| `heat_call_to_start.wav` | «На старт приглашаются.» |
| `transponder_check.wav` | «Проверка транспондеров. Совершите контрольный проход.» |
| `all_pilots_ready.wav` | «Все пилоты готовы.» |
| `waiting_for_pilots.wav` | «Ожидаем пилотов на старте.» |

После `heat_call_to_start.wav` приложение по очереди воспроизводит загруженные имена пилотов.

## Ход гонки

| Файл | Текст |
| --- | --- |
| `new_best_lap.wav` | «Новый лучший круг.» |
| `new_leader.wav` | «Новый лидер заезда.» |
| `one_minute_left.wav` | «До окончания заезда одна минута.» |
| `thirty_seconds_left.wav` | «До окончания заезда тридцать секунд.» |
| `time_expired.wav` | «Время заезда истекло.» |
| `finish_current_lap.wav` | «Пилоты завершают текущий круг.» |
| `last_lap.wav` | «Последний круг.» |

Для лучшего круга естественный порядок: `new_best_lap.wav` → имя пилота. Время круга остаётся на экране, пока не будет подготовлен отдельный набор чисел.

## Финиш

| Файл | Текст |
| --- | --- |
| `pilot_finished.wav` | «Закончил гонку.» |
| `heat_finished.wav` | «Заезд завершён.» |
| `all_pilots_finished.wav` | «Все пилоты финишировали.» |
| `race_stopped.wav` | «Заезд остановлен судьёй.» |

Порядок индивидуального объявления: имя пилота → `pilot_finished.wav`.

## Результаты заезда

| Файл | Текст |
| --- | --- |
| `heat_results.wav` | «Результаты заезда.» |
| `place_1.wav` | «Первое место.» |
| `place_2.wav` | «Второе место.» |
| `place_3.wav` | «Третье место.» |
| `place_4.wav` | «Четвёртое место.» |
| `place_5.wav` | «Пятое место.» |
| `place_6.wav` | «Шестое место.» |
| `winner.wav` | «Победитель заезда.» |
| `results_saved.wav` | «Результаты сохранены.» |

Порядок оглашения: `heat_results.wav` → место → имя пилота. Для финального заезда первое место можно объявлять как `winner.wav` → имя пилота.

## Служебные сообщения

| Файл | Текст |
| --- | --- |
| `false_start.wav` | «Фальстарт.» |
| `lap_not_counted.wav` | «Круг не засчитан.» |
| `unknown_transponder.wav` | «Неизвестный транспондер.» |
| `lapwiz_disconnected.wav` | «Связь с системой засечки потеряна.» |
| `lapwiz_connected.wav` | «Система засечки подключена.» |
| `pause.wav` | «Заезд приостановлен.» |
| `continue.wav` | «Заезд продолжается.» |

Служебные сообщения стоит включать только при реальном событии, чтобы диктор не говорил слишком часто.
