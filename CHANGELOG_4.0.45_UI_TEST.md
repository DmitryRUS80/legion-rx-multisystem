# Legion RX 4.0.45 UI TEST

- К реальному пульту RallyCross применён экспорт `legion-rx-ui.json` из Legion RX UI Lab.
- Добавлены отдельные сохранённые размеры и позиции для desktop, compact, tablet, phone landscape и phone portrait.
- В вертикальном телефоне скрыты только AVG и круги — BEST, отставание, статус, флаг и подпись пилота оставлены по сохранённому профилю.
- Верхние кнопки, высоты блоков, колонки пилотов, таймер, круг, показатели лидера, пульт и нижняя панель используют значения из JSON.
- Исходный применённый профиль включён в сборку как `legion-rx-ui-applied.json`.
- Логика гонки, LapWiz, диктора и локальной базы данных не изменялась.
