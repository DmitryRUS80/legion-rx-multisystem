# Legion RX 4.0.47 UI TEST

- Пульт RallyCross перенесён на нативную DOM-структуру UI Lab вместо наложения параметров на старую разметку.
- Шапка колонок и строки пилотов используют одну семиколоночную сетку.
- Таймер, круг, статистика, кнопки и нижняя панель повторяют структуру и профили экспортированного JSON.
- Вертикальный телефон использует тот же порядок блоков, что и UI Lab: таймер, пилоты, управление, нижняя панель.
- Возвращено плавное перемещение строк пилотов при изменении позиции (FLIP-анимация, совместимая с Safari).
- Логика соревнований, LapWiz, диктор, база пилотов и аудиофайлы не изменялись.
