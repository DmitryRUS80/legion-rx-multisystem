# Legion RX 4.0.35 TEST

- Добавлены 12 локальных WAV-фраз диктора из `Sound.rar`.
- Все фразы и загруженные имена пилотов воспроизводятся через общую очередь без наложения.
- За минуту до старта: предупреждение → «На старт приглашаются» → имена пилотов.
- Перед отсчётом звучит «Хорошей гонки», затем счёт от выбранного значения (1–10) до 1 и HORN.
- Новый лучший круг: «Новый лучший круг» → имя пилота. Секунды и миллисекунды не озвучиваются.
- Финиш пилота: имя → «Закончил гонку».
- Добавлены объявления истечения времени, завершения текущего круга, результатов, неизвестного транспондера, потери связи LapWiz и остановки судьёй.
- В настройках появились отдельные переключатели вызова на старт, лучшего круга, финиша, результатов и служебных сообщений.
- Голоса пилотов по-прежнему загружаются вручную и хранятся локально в IndexedDB без API и интернета.
