# Legion RX 4.0.37 TEST

- Для iOS/PWA аудиосессия теперь явно признаётся недействительной после сворачивания приложения или `pagehide`.
- При возврате показывается настоящее восстановление звука одним касанием.
- Старые HTML Audio elements после iOS-прерывания удаляются и создаются заново; ложный статус «звук включён» больше не сохраняется.
- Добавлена отдельная телефонная горизонтальная компоновка: пилоты слева, таймер и шесть кнопок управления справа.
- Карточки пилотов в landscape сделаны двухстрочными, чтобы сохранить имя, лучший/последний круг, круги и статус.
