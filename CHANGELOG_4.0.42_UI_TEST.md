# Legion RX 4.0.42 UI TEST

- Пульт RallyCross пересобран по утверждённому тёмному эскизу на новой изолированной разметке.
- Сохранена композиция эскиза: верхний информационный блок, участники слева, таймер и управление справа, нижняя информационная панель.
- В таблицу возвращены крупное имя пилота, клуб и ID, лучший круг, средний круг, круги, отставание и статус.
- Таймер получил крупные цифры, круговой индикатор и три показателя лидера.
- Кнопки управления имеют постоянную геометрию. Недоступное состояние больше не меняет прозрачность, размеры и положение внутреннего содержимого.
- Новый UI находится в отдельном файле `ui-rally-4.0.42.css` и не использует старые классы геометрии RallyCross.
- Логика соревнования, LapWiz Core, обработка кругов, результаты и диктор не изменялись.
