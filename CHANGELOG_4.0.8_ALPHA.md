# Legion RX 4.0.8 Alpha — Announcer Start

## Голосовой движок
- Добавлен общий Announcer Engine, независимый от RallyCross Engine.
- Подключены пользовательские WAV/MP3 из `Sound.zip`.
- Добавлен полный и короткий сценарий старта.
- HORN запускается на нулевой отметке одновременно с командой начала заезда.
- STOP во время отсчёта отменяет голосовую последовательность и возвращает заезд в готовность.

## LapWiz
- Стандартный синтезированный blip для валидного прохода заменён на пользовательский `Bleep.MP3`.
- Bleep имеет 8 параллельных каналов для близких проходов.
- Unknown ID остаётся отдельным диагностическим сигналом и не попадает в результат.

## UI
- В настройках появился рабочий раздел «Диктор · старт».
- В пульте статус диктора активный, а не «скоро».
- Виджет диктора показывает выбранный сценарий и состояние Bleep.
