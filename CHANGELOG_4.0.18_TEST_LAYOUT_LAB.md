# Legion RX 4.0.18 TEST — Clean Cockpit / Layout Lab

Отдельная экспериментальная сборка на базе 4.0.17. Спортивная логика RallyCross, Track Day, PIT, LapWiz и мобильное аудио не менялись.

## Что изменено
- Исправлен контраст текста кнопки возврата в активное событие на главной странице.
- Убрана постоянная правая колонка подробных виджетов из рабочего пульта RallyCross.
- Основная рабочая область теперь состоит из таблицы пилотов и таймера; место справа освобождено.
- Нажатие на верхний статус LapWiz открывает отдельную панель LapWiz.
- Нажатие на верхний статус заезда/прогрева открывает панель состояния и предстартовой автоматики.
- Нажатие на верхний статус диктора открывает панель голосового сопровождения.
- Нажатие на блок текущего заезда открывает панель следующего заезда/результатов.

## Layout Lab
На пульте добавлена отдельная кнопка Layout Lab. В режиме редактирования можно:
- перетаскивать шапку;
- перетаскивать ход соревнования;
- перетаскивать таблицу пилотов;
- перетаскивать таймер;
- перетаскивать блок управляющих кнопок;
- перетаскивать нижнюю строку режимов;
- изменять размер каждого блока за правый нижний угол.

Положение и размеры сохраняются в localStorage как относительные координаты, поэтому макет адаптируется при изменении размера окна.

Кнопка «Копировать схему» копирует JSON расположения блоков. «Сбросить» возвращает штатный макет. «Готово» выходит из Layout Lab, сохраняя найденную компоновку.

Это TEST-сборка для поиска будущей компоновки интерфейса, а не замена стабильной 4.0.17.
