# Legion RX 4.0.17 Alpha — RallyCross Quick Race Management

Основа: 4.0.16 Alpha.

Изменения только в управлении RallyCross:
- На пульте добавлена явная кнопка «Пропустить».
- «Пропустить» после подтверждения отменяет только текущий заезд без результата и переводит программу к следующему событию.
- На пульте добавлена явная кнопка «Отмена / завершение».
- «Отмена / завершение» открывает существующее расширенное управление: отмена 1/2/3/5 заездов, отмена текущей квалификационной серии, досрочное завершение квалификации, завершение соревнования.
- На мобильном обе кнопки остаются доступны в шапке как отдельные иконки.

Track Day, PIT, LapWiz Core и аудиослой не изменялись.
