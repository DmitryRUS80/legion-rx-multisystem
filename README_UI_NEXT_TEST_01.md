# Legion RX 4.1.0 — UI NEXT TEST 01

Первая тестовая сборка нового визуального слоя Legion RX поверх проверенного рабочего ядра 4.0.42.

## Что изменено

- Новый RallyCross cockpit: отдельный `ui-next.js` + `ui-next.css`.
- Новая строка пилота: POS → ID → NAME → FLAG → GAP → ✓ → BEST → AVG → LAST → LAPS.
- На телефоне в портрете — компактная строка с динамической правой зоной PACE/GAP.
- На iPad в портрете — полный набор метрик и переключатели GAP / ✓ / BEST / AVG / LAST / LAPS под кнопками пульта.
- Оставшиеся колонки iPad после отключения автоматически делят свободную ширину.
- Малые миллисекунды после точки.
- Встроенная линия прогресса текущего круга в строке пилота.
- Плавное FLIP-перемещение строк при изменении позиции.
- Новый верхний пульт: Bluetooth, LapWiz, Диктор, Статус, Пропустить, Завершить, Результаты, Настройки, Меню.
- Новый правый пульт: таймер, круговой индикатор и 6 кнопок управления.
- Track Day и остальные разделы приведены к общей тёмной визуальной системе без изменения их спортивной логики.

## Что НЕ переписывалось

Не переписывались BLE/LapWiz Core, спортивная логика квалификаций/финалов, обработка проходов, Min Lap, Track Day, диктор/аудио, IndexedDB/localStorage, Service Worker и расчёт результатов. Новый cockpit подключается как визуальная граница после основного рабочего скрипта.

## Запуск

Для полной проверки разместите содержимое архива в корне GitHub Pages/HTTPS-хостинга. Web Bluetooth требует HTTPS и поддерживаемый браузер (в текущем ядре — Chrome/Android). На первом запуске приложение проверит OFFLINE-пакет и локальное аудио.
