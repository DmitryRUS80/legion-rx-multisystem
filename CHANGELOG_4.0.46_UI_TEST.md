# Legion RX 4.0.46 UI TEST

- Удалены старые адаптивные media-правила RallyCross, которые продолжали влиять на профиль из UI Lab по более высокой CSS-специфичности.
- В вертикальном телефоне AVG и круги теперь скрываются одновременно и в шапке, и в каждой строке пилота; статус больше не переносится во второй неявный ряд.
- Блок управления занимает всю сохранённую высоту и снова показывает шесть полноразмерных кнопок вместо тонких полос.
- Вертикальный таймер уплотнён внутри сохранённой высоты: подписи, цифры и показатели больше не накладываются друг на друга.
- Верхнее меню больше не появляется лишней четвёртой кнопкой под шапкой.
- Добавлен локальный шрифт Legion Narrow, чтобы iOS, Android и компьютер использовали одинаковые метрики текста без зависимости от системного Bahnschrift.
- Обновлены версия приложения, manifest и оба offline-кэша.
- Логика соревнований, LapWiz, звука, диктора и база данных не изменялись.
