# CHANGELOG RC14 OSWALD

- Единый UI-шрифт приложения: Oswald.
- Подключены веса 400 / 500 / 600 / 700 для кириллицы и латиницы.
- Шрифт применяется через существующие авторитетные UI-переменные; поздний CSS override не добавлялся.
- Геометрия строк пилотов, размеры блоков и спортивная логика не менялись.
- Web-font ресурсы включены в OFFLINE-кэш приложения.
