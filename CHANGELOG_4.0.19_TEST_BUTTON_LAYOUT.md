# Legion RX 4.0.19 TEST — Independent Control Buttons

Экспериментальная UI-сборка на основе 4.0.18 TEST.

- Нижняя панель RallyCross разбита на 7 независимых кнопок.
- Добавлена нижняя кнопка «Пропустить заезд».
- В Layout Lab каждая кнопка двигается и масштабируется отдельно.
- Кнопку можно скрыть через ×.
- В панели Layout Lab → «Кнопки» можно вернуть скрытый элемент.
- Макет и видимость сохраняются в localStorage (`legionrx4_layout_lab_v2`).
- Рабочая логика соревнования, звук, LapWiz, Track Day и PIT не менялись.
