# Legion RX 4.1.0 — UI NEXT TEST 04

TEST 04 продолжает новый изолированный `rxn*` UI без изменения спортивной логики, BLE/LapWiz, аудио и хранилища.

## Изменения TEST 04

- Точность `0.1` и `0.01`: дробная часть отображается тем же размером, что и секунды.
- Точность `0.001`: только три тысячные после точки отображаются уменьшенным размером.
- Track Day / Free Practice переведён на тот же новый cockpit DOM и тот же визуальный пульт, что RallyCross.
- В Free Practice шесть ячеек пульта: активная практика, пауза, финиш, **СТАТИСТИКА** вместо `+1 МИН`, ручной круг, стоп.
- Под пультом Free Practice используются те же переключатели столбцов и точности времени.
- Таблица Free Practice использует тот же новый тип строк пилотов: ID, имя, флаг, GAP, статус, BEST, AVG, LAST, LAPS и прогресс текущего круга.
- Ручной проход Free Practice вызывается отдельной кнопкой нового пульта и передаётся в существующую `processTrackPass()`.
- Старый Track Day cockpit DOM в TEST 04 не используется; рабочая Track Day логика PIT/PIT OUT/LapWiz остаётся в `index.html`.

## Что не менялось

BLE-протокол LapWiz, START/STOP, обработка проходов, RallyCross-логика, квалификации/финалы, диктор, IndexedDB/localStorage, Service Worker механика и расчёты времени не переписывались.
