# Legion RX 4.1.0 — UI NEXT TEST 02

Тестовая сборка нового UI без изменения спортивной/BLE/audio логики.

## Что изменено относительно TEST 01

- Desktop: строки пилотов масштабируются по высоте экрана так, чтобы на типичном 1792×864/1920×1080 помещалось примерно 8–10/10–11 строк, а не около 20.
- Desktop и планшеты landscape: таблица пилотов занимает всю доступную ширину; GAP / ✓ / BEST / AVG / LAST / LAPS равномерно используют свободное место, без наложения цифр.
- Android/iPad portrait от 600 CSS px: полный набор данных пилота показывается сразу.
- Portrait tablet: имя и флаг собраны плотнее; флаг остаётся отдельной выровненной колонкой сразу после имени.
- Под пультом portrait tablet всегда доступны переключатели GAP / ✓ / BEST / AVG / LAST / LAPS. После отключения колонки оставшиеся метрики автоматически растягиваются равномерно до правого края.
- Для переключателей используется новый UI-key, поэтому TEST 02 стартует со всеми колонками включёнными.
- Обновлён offline cache, чтобы GitHub Pages/PWA не держал CSS/JS от TEST 01.

## Что не менялось

Race logic, LapWiz BLE core, START/STOP, проходы транспондеров, спортивные расчёты, диктор/audio, IndexedDB/localStorage приложения и Service Worker-механика не переписывались. Изменения относятся к UI NEXT и версии cache/name.
