# Legion RX 4.0.7 Alpha — Mobile Cockpit Fix

- Rebuilt cockpit responsiveness for portrait phones instead of shrinking the desktop grid.
- Timer stays large at the top of the working area; leaderboard occupies the main remaining height.
- Secondary widgets are hidden from the race workspace and open in a dedicated mobile sheet via “Виджеты”.
- Widget sheet is scrollable and no longer overlaps controls/table unpredictably.
- Bottom controls are a fixed 2×3 grid on portrait screens.
- Compact mobile event strip.
- Reduced leaderboard columns on narrow screens while retaining POS / pilot / laps / best lap / gap.
- Added one web typography source (Roboto Condensed) so Windows and Android render closer to each other; fallbacks remain if offline.
- PWA cache bumped to 4.0.7.
