# Legion RX 4.1.0 — UI NEXT TEST 05

## Восстановлено и закреплено

- Единый авторитетный блок спортивных правил `SPORT_RULES`:
  - квалификация: 50 / 45 / 42 / 40 / 39 / 38 / ...;
  - Best 3;
  - статусы FIN / DNF / DNS / DSQ;
  - финалы A1 / A2 / A3;
  - учитываются 2 лучших результата из 3;
  - не-FIN в сумме Финала A = 7;
  - очки этапа чемпионата: 25 / 18 / 15 / 12 / 10 / 8 / 6 / 4 / 2 / 1.
- Продолжение таблицы квалификационных очков после 16-го места исправлено без скачка: 17-е = 27, далее -1 до минимума 1.
- Новый обязательный экран подтверждения результата после каждого заезда.
- В нём доступны FIN / DNF / DNS / DSQ и ручная коррекция места перед сохранением.
- DNS предлагается автоматически пилоту, который вообще не был засечён; судья может изменить статус.
- DNF теперь получает последовательный DNF-order среди DNF, а не номер строки.
- Статусы сохраняются в квалификации, LCQ и A1/A2/A3 и отображаются в таблицах результатов.
- Финальный протокол сохраняет историю A1/A2/A3 в поле источника, включая DNF/DNS/DSQ и расчёт лучших двух.
- В финальной части добавлена кнопка `СТАРТОВАЯ РЕШЁТКА`.
- Порядок вызова в финалах явно сортируется по квалификационному рейтингу; подтверждённая решётка сохраняется в данных гонки.
- Диктор при вызове на старт в финалах использует квалификационный рейтинг.
- На пульте после финиша кнопка `СЛЕДУЮЩИЙ` заменена на `РЕЗУЛЬТАТ / ПОДТВЕРДИТЬ`, чтобы нельзя было незаметно сохранить всех как FIN.
- Экран `РЕЗУЛЬТАТЫ` показывает версию спортивных правил, Q-очки, Best 3, A1/A2/A3, статусы и очки этапа.

## Не затрагивалось

- BLE/LapWiz протокол и команды START/STOP.
- обработка проходов и Min Lap;
- таймеры и расчёт кругов;
- Track Day / Free Practice;
- аудиофайлы и локальные записи имён;
- IndexedDB/localStorage;
- адаптивный cockpit TEST 04, кроме добавления решётки и подтверждения результата.

В комплекте есть `SPORT_TEST_REPORT.json`. Автотесты прошли: квалификационные очки, Best 3, DNF/DNS, A1/A2/A3, итоговый протокол, очки этапа, новый экран подтверждения, стартовая решётка и размеры модального окна 390×844 / 820×1180 / 1280×800.
