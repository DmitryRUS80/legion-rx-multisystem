# Legion RX 4.0.27 TEST — Adaptive Cockpit

## Что изменено
- RallyCross cockpit переведён с подгонки под конкретный планшет на fluid/adaptive layout.
- Landscape: участники слева, таймер/круг/управление справа.
- Phone portrait: верхняя строка LEGION RX + все статусные кнопки, затем таймер и круг, участники, затем весь блок управления и строка следующего заезда.
- Размеры шрифтов, строк пилотов, кнопок, таймера, колец и отступов плавно масштабируются от телефона/планшета до Full HD/2K.
- На больших desktop viewport интерфейс больше не остаётся «планшетного» микроскопического размера.
- Таблица пилотов имеет собственный scroll и не двигает таймер/управление.
- Для узких экранов строка пилота перестраивается в двухстрочную карточку без горизонтального скролла: имя + круги + статус / BEST + AVG + отставание.
- На телефоне все семь верхних управляющих/status кнопок остаются доступны как компактные icon buttons.
- Убрано дублирование нижних виджетов Результаты / LapWiz / Диктор. Снизу справа осталась только полезная строка «Следующий заезд».
- Dark и Light используют одинаковую адаптивную геометрию.

## Не изменялось
- спортивная логика RallyCross;
- LapWiz Core / BLE;
- Offline Audio 27/27;
- Track Day;
- PIT;
- логика стартового диктора.
