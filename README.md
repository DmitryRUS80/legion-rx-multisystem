# Legion RX 4.0.10 Alpha — Warmup Voice

Основа: 4.0.8 Announcer Start.

## Что добавлено
- Настраиваемый предстартовый прогрев: 1–5 минут.
- Выбранные минуты — полное время от нажатия `СТАРТ / ПРОГРЕВ` до HORN. Финальный отсчёт 1–10 секунд входит в это время и не прибавляется сверху.
- В начале прогрева LapWiz запускается в `Free Practice` и остаётся в этой аппаратной сессии через HORN и начало гонки.
- В Free Practice поддержан второй этап штатного протокола SkyRC: после первого IR-прохода отправляется `START_TIMING(0)` / command `0x06`.
- Во время прогрева каждый валидный проход зарегистрированного транспондера даёт пользовательский Bleep.
- На пульте показывается `обнаружено X / N`; у пилота появляется `НА ТРАССЕ ✓`. Повторные проходы не увеличивают X / N.
- После HORN предстартовый счётчик скрывается, гоночный таймер стартует с нуля.
- Первый проход пилота после HORN: Bleep + `СТАРТ ✓`, круг не добавляется.
- Следующий проход становится кругом 1. Его время считается от HORN, поэтому первый круг может быть длиннее последующих, если засечка находится после стартовой решётки.
- Последующие круги используют аппаратные интервалы LapWiz (`workTicks`, 10 мс на тик) с резервом по таймеру приложения.

## Предстартовый диктор
В 4.0.10 минутные отметки 5/4/3/2/1 и фраза «30 секунд» переведены на записанные WAV пользователя. Отдельной записанной фразы приглашения на трассу в voice-pack пока нет, поэтому только эта короткая часть временно остаётся через SpeechSynthesis.

Для полной замены системного голоса на штатный голос Legion RX нужны файлы из `VOICE_WARMUP_TODO.txt`.

## Важно для полевого теста
Главная проверка 4.0.10 — убедиться на реальном LapWiz, что одна сессия Free Practice стабильно переживает прогрев → HORN → весь заезд без STOP/START на старте.
