# Legion RX 4.0.8 Alpha — Announcer Start

Основа: 4.0.7 Mobile Cockpit Fix.

## Новое
- Общий Announcer Engine для всех будущих дисциплин.
- Реальные аудиофайлы пользователя в `audio/`.
- Два сценария старта:
  - Полный: «До старта 10 секунд» → 10…5 → на 4 «Хорошей гонки» → молча до 0 → HORN → START.
  - Короткий: «Хорошей гонки» → N-1…1 → HORN → START.
- Отсчёт задаётся в настройках (1–10 сек).
- Пользовательский `Bleep` звучит на каждом валидном проходе LapWiz зарегистрированного пилота.
- Для близких проходов используется несколько звуковых каналов Bleep.
- Неизвестный транспондер по-прежнему не засчитывается и имеет отдельный диагностический сигнал.
- PWA-кэш включает все голосовые файлы.

## Тест
Для Bluetooth нужен Chrome на Android/Windows + HTTPS (GitHub Pages).
Аудио можно проверить в Настройки → Диктор / LapWiz без Bluetooth.
