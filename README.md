# Legion RX 4.1.0 UI NEXT TEST 06

Тестовая сборка после реального Track Day.

## Что изменено

- В свободной практике судья может открыть круги пилота и убрать ошибочно засчитанный круг.
- После удаления автоматически пересчитываются: число кругов, BEST, AVG, LAST и рейтинг Track Day.
- Та же коррекция работает для уже сохранённых Track Day через «Отчёт» → пилот → список кругов.
- Каждая коррекция сохраняется в `corrections[]`: удалённое время и факт судейского вмешательства не теряются.
- Старые сохранённые Track Day мигрируют в схему v2 автоматически; ключи localStorage не менялись.
- Автоинформатор в Free Practice теперь объявляет нового абсолютного лидера по лучшему кругу: системная фраза «новый лучший круг» + локально загруженное имя пилота.
- RallyCross SPORT_RULES, BLE/LapWiz, START/STOP, Min Lap и протокол засечки не переписывались.

## Важно

Min Lap остаётся только аппаратно/логическим нижним порогом. Например при Min Lap = 6.0 с ложный проход 6.01 с формально допустим, поэтому судейская коррекция нужна как штатный инструмент.

Для обновления GitHub Pages замените содержимое предыдущей сборки содержимым этой папки. Service Worker cache поднят на `ui-next-test-06`; локальные данные пилотов, соревнований и Track Day не очищаются.

См. `TRACK_DAY_TEST_REPORT.json` и `TEST_CHECKLIST_UI_NEXT_06.txt`.
