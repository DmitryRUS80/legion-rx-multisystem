# Legion RX 4.0.13 Alpha — Mobile Audio Fix

Основа: 4.0.10 Alpha Warmup Voice.

## Тайминг и прогрев
- Настраиваемый предстартовый прогрев: 1–5 минут.
- Выбранные минуты — полное время от нажатия `СТАРТ / ПРОГРЕВ` до HORN. Финальный отсчёт 1–10 секунд входит в это время.
- LapWiz в начале прогрева запускается в `Free Practice` и остаётся в этой аппаратной сессии через HORN и начало гонки.
- После первого IR-прохода Free Practice поддерживается `START_TIMING(0)` / command `0x06`.
- До старта валидные проходы дают Bleep и отмечают пилота `НА ТРАССЕ ✓`.
- После HORN первый проход = Bleep + `СТАРТ ✓`, без добавления круга.
- Следующий проход становится кругом 1; первый круг считается от HORN.

## Новый Mobile Audio Fix 4.0.13
- Единый Web Audio `AudioContext` вместо независимых `Audio()` для штатных файлов.
- Две независимые шины: `VOICE` и `SFX`.
- Bleep и HORN могут играть поверх WAV диктора и не должны обрывать его.
- Первое касание экрана разблокирует мобильный аудиоканал.
- При возврате из фона приложение пытается восстановить AudioContext.
- В интерфейсе показывается состояние Mobile Audio Fix.

Минутные отметки 5/4/3/2/1, «30 секунд», стартовые цифры, «Хорошей гонки», HORN и Bleep используют пользовательские файлы из проекта. Только фраза приглашения участников на трассу пока временно остаётся системным SpeechSynthesis до появления отдельного WAV.

## Платформы
- Android/Windows: основной рабочий путь с LapWiz — Chrome + HTTPS/Web Bluetooth.
- iPhone: UI и Mobile Audio Fix работают как веб/PWA, но Web Bluetooth для LapWiz остаётся отдельной платформенной задачей.
