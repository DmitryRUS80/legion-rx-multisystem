# Legion RX 4.0.2 Alpha

Новая мультисистемная оболочка Legion RX.

## Работает в 4.0.2
- Главный экран с выбором дисциплин.
- RallyCross: новая настройка события + одноэкранный пульт.
- Спортивная логика RallyCross перенесена из Championship Edition v3.4: snake-разбиение квалификаций, очки 50/45/42..., Best 3, tie-break, LCQ-переходы, A1/A2/A3 и итоговые очки этапа.
- Общая база пилотов и ID транспондеров.
- Чемпионаты и накопление очков завершённых этапов.
- LapWiz BLE Core: FFF0 / FFF3 / FFF4, START / STOP, ID и deviceTicks.
- Ручной проход как резерв.
- Светлая / тёмная тема.
- Русский / английский переключатель оболочки (английский словарь пока частичный).
- PWA/service worker.

## Пока неактивно (серое)
- Rally Sprint.
- Classic RC.
- Расписание / автоматизация запуска по времени.
- Диктор.
- Broadcast / OBS.
- Пауза и +1 минута в живом пульте.

## Важно
LapWiz проверяется на Android Chrome через HTTPS. Эта Alpha — отдельная сборка и не заменяет v3.4 автоматически.
