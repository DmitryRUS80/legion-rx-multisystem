LEGION RX — КАК ОБНОВЛЯТЬ ПРОЕКТ НА GITHUB БЕЗ ЛИМИТА 100 ФАЙЛОВ

Лучший вариант для Дмитрия: GitHub Desktop. Через сайт GitHub файлы больше не загружать.

ОДИН РАЗ:
1. Установить GitHub Desktop.
2. Войти в свой GitHub-аккаунт.
3. File -> Clone repository.
4. Выбрать существующий репозиторий Legion RX.
5. Нажать Clone.

КАЖДАЯ НОВАЯ ВЕРСИЯ LEGION RX:
1. Скачать ZIP, который дал ChatGPT.
2. Распаковать ZIP в отдельную папку.
3. В GitHub Desktop открыть Repository -> Show in Explorer.
4. В открывшейся папке репозитория удалить старые ВИДИМЫЕ файлы и папки проекта.
   ВАЖНО: папку .git не удалять. Обычно она скрыта Windows и её вообще не видно.
5. Из новой распакованной сборки скопировать ВСЁ содержимое папки проекта в папку репозитория.
   В корне репозитория после копирования должен лежать index.html.
6. Вернуться в GitHub Desktop. Он сам покажет все добавленные, изменённые и удалённые файлы.
7. Внизу слева в Summary написать, например: Legion RX 4.2.0 RC3.
8. Нажать Commit to main.
9. Нажать Push origin.
10. Готово. Ограничения в 100 файлов веб-загрузки здесь нет.

ПРАВИЛО РАЗРАБОТКИ LEGION RX:
GOLD никогда не перезаписывать. Для любой правки делать RC-копию.
Перед изменением определить радиус: какой модуль можно трогать и какие нельзя.
Локальная правка не должна превращаться в пересборку всего проекта.
В финальной версии не оставлять patch.js, fix.css, runtime overrides и дубли функций.

КАК СТАВИТЬ ЗАДАЧУ CHATGPT:
LEGION RX. Хирургическая правка.
База: [название версии].
Задача: [что нужно изменить].
Сначала укажи радиус изменения: какие файлы нужно тронуть и какие модули трогать запрещено.
Не пересобирай проект целиком. Не меняй соседние модули без необходимости.
После правки дай новый RC-архив и отчёт: изменённые файлы, что не трогалось, какие тесты прошли.
